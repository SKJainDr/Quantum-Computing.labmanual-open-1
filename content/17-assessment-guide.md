<h1 id="assessment-guide-lab-record-and-examination">Assessment Guide — Lab Record and Examination</h1><h2 id="lab-record-requirements-each-experiment">Lab Record Requirements (Each Experiment)</h2><ul>
<li><p>Title and experiment number (must match this manual exactly)</p></li>
<li><p>Date performed, student name, roll number, and batch identifier</p></li>
<li><p>Aim: one concise sentence stating what the experiment demonstrates</p></li>
<li><p>Theory: minimum 3–5 equations with Dirac notation and 4–6 sentences of explanation</p></li>
<li><p>AQLL screenshots (Phase 1, Experiments 1–11): at least 2 figures with descriptive captions</p></li>
<li><p>Circuit Diagram: generated using qc.draw('mpl') — must include all gate labels</p></li>
<li><p>First Program: simple code version printed or pasted in full</p></li>
<li><p>Full Program: complete, commented code version printed or pasted in full</p></li>
<li><p>Completed Observation Tables: filled during the session using actual experimental data</p></li>
<li><p>Simulation output: histogram or statevector plot (saved PNG from code execution)</p></li>
<li><p>IBM Hardware results (Experiments 13–15): screenshot with Job ID clearly visible</p></li>
<li><p>Analysis: comparison table (simulation vs hardware), quantitative error discussion, conclusions</p></li>
<li><p>Answers to all Discussion Questions listed in this manual</p></li>
